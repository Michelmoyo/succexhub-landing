Politique de confidentialité

Dernière mise à jour : 5 novembre 2026

En bref : nous utilisons vos coordonnées uniquement pour organiser votre venue à la rencontre Succexhub et, si vous l'acceptez, pour vous envoyer un rappel sur WhatsApp. Le site utilise le Meta Pixel pour mesurer l'efficacité de nos publicités. Nous ne vendons jamais vos données. Vous pouvez à tout moment demander leur suppression.

1. Qui est responsable de vos données

Le site business.succexhub.com est édité par Schadrac Ngoy, porteur de Succexhub, Avenue Lac Moero 279, Kinshasa, République démocratique du Congo.

Pour toute question sur vos données : WhatsApp +243 812 941 930.

2. Les données que nous collectons

Lors de votre réservation

  • votre prénom et, si vous le donnez, votre nom ;
  • votre numéro WhatsApp ;
  • la date de rencontre choisie ;
  • votre choix de recevoir ou non un rappel.

Le site n'enregistre pas ces informations sur un serveur. Elles servent à préparer le message WhatsApp de réservation. Nous les recevons uniquement si vous envoyez ce message.

Lors de votre visite, avec le Meta Pixel

Le site utilise le Meta Pixel, un outil de mesure fourni par Meta Platforms (Facebook, Instagram). Il enregistre :

  • les pages consultées et certaines actions : ouverture de la réservation, validation du formulaire, clic sur le bouton WhatsApp, avec la date choisie ;
  • des informations techniques : type d'appareil et de navigateur, adresse IP, identifiants de cookies.

Lorsque vous validez le formulaire, votre prénom, votre nom et votre numéro de téléphone sont aussi transmis au Meta Pixel. Ils sont chiffrés (hachés) dans votre navigateur avant l'envoi : Meta ne reçoit pas ces informations en clair. Il les utilise pour relier votre visite à un compte Facebook ou Instagram, afin de mesurer les résultats de nos publicités.

Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc.). Comme tout hébergeur, GitHub peut enregistrer des données techniques de connexion, dont l'adresse IP, pour assurer la sécurité et le fonctionnement du service.

3. Pourquoi nous utilisons ces données

  • Organiser la rencontre : confirmer votre place et vous accueillir.
  • Vous envoyer un rappel, uniquement si vous avez coché la case prévue.
  • Mesurer et améliorer nos publicités sur Facebook et Instagram, et les montrer à des personnes susceptibles d'être intéressées.

4. Qui reçoit vos données

  • Succexhub, pour l'organisation des rencontres.
  • Meta Platforms, pour le Meta Pixel et pour WhatsApp, selon sa politique de confidentialité.
  • GitHub, pour l'hébergement, selon sa déclaration de confidentialité.

Nous ne vendons ni ne louons vos données.

5. Combien de temps nous les conservons

  • Vos échanges WhatsApp avec Succexhub : le temps nécessaire au suivi de votre participation, et au plus 12 mois après notre dernier échange, sauf si vous demandez leur suppression avant.
  • Les données du Meta Pixel : selon les durées fixées par Meta.

6. Vos droits

Vous pouvez à tout moment :

  • savoir quelles données nous détenons sur vous ;
  • les faire corriger ou supprimer ;
  • arrêter les messages : répondez STOP sur WhatsApp, l'arrêt est immédiat ;
  • limiter les publicités personnalisées dans les préférences publicitaires de votre compte Meta.

Pour exercer ces droits, écrivez-nous sur WhatsApp au +243 812 941 930. Nous répondons dans un délai d'un mois au maximum.

7. Cookies

Le Meta Pixel dépose des cookies dans votre navigateur pour reconnaître votre visite. Vous pouvez les bloquer ou les supprimer dans les réglages de votre navigateur. La page de réservation continuera de fonctionner.

8. Modifications

Nous pouvons mettre à jour cette politique, par exemple si nous ajoutons un outil. La date de mise à jour en haut de page indique la version en vigueur.
